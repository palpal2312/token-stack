# Benchmark Outputs Directory

This directory is the local destination for benchmark dossiers and evaluation reports generated by `benchmark-tui.cjs`.

When you run:
```bash
node ./skills/token-stack-benchmark/scripts/benchmark-tui.cjs
```
Evaluation dossiers (`00-problem-and-dataset.md`, `01-evaluation-metrics.md`, `02-agent-output.md`) for all 5 scenarios will be automatically generated in subfolders here.
