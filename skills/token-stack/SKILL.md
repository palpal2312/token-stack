# Token Stack Router

4 Core Token-Reduction Layers + 1 Optional Pluggable Memory Layer:

- **Core Layer 1 (ponytail)**: less code through reuse, stdlib, and YAGNI.
- **Core Layer 2 (caveman)**: fewer words without dropping technical precision.
- **Core Layer 3 (RTK)**: filters verbose CLI command outputs.
- **Core Layer 4 (Headroom)**: local proxy compresses API context and caches prompt prefix.
- **Optional Layer 5 (Memory)**: cross-session long-term memory (MemoraX Code, Mem0 MCP, Local Knowledge).

Route by intent:

- **Health**: use `token-stack:health` for directory, profile, harness, model, 4 core layers, and optional memory layer status. Read-only.
- **Setup**: use `token-stack:setup` for RTK/caveman/ponytail setup, or run `scripts/install-memory-layer.ps1` for Layer 5 Memory.
- **Report**: use `token-stack:report` for observed counters and savings.
